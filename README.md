# Personal Expense Tracker (Go)

A simple console-based expense tracker built using Go (Golang). I created this project to practice Go fundamentals and understand how to organize and manage data in a program.

## Features

- Add a new expense with its title and amount.
- View all recorded expenses.
- Calculate the total amount spent.
- Menu-based interface to navigate through the application.
- Basic validation for expense amounts.

## Technologies Used

- Go (Golang)
- Structs
- Slices
- Functions
- Loops and Conditional Statements
- Console Input/Output

## How to Run

Make sure Go is installed on your system.

1. Clone the repository:

```bash
git clone https://github.com/bittubpsindia/GoLang_Personal-Expense-Tracker.git
```

2. Open the project folder:

```bash
cd GoLang_Personal-Expense-Tracker
```

3. Run the application:

```bash
go run main.go
```
