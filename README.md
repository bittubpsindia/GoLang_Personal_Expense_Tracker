# Personal Expense Tracker (Go)

A simple command-line application developed using Go (Golang) to manage daily expenses.

## Features
- Add new expenses
- View all recorded expenses
- Calculate total expenses
- Menu-driven console interface

## Technologies Used
- Go (Golang)
- Structs
- Slices
- Functions
- Loops and Conditional Statements
- Console Input/Output

## How to Run

1. Clone this repository.
2. Open the project directory.
3. Run the application:

```bash
go run main.go
```

This project demonstrates basic Go programming concepts through a practical console-based application.
